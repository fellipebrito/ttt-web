# Cut Line — Landing Page (v5)

Single-page landing site for **Cut Line**, the putting-practice app from the
Tee Time Trainer team. Lives at `teetimetrainer.app/cutline`.

Rebuilt July 2026 on the app's **v5 design system** (mirrors
`cutline/src/design/v5.ts` in the app repo): dark felt gradient
`#052D19 → #0A4728`, gold `#F3D653`, glass panels, fonts BBH Bogle
(headings) / BBH Bartle (display) / DM Sans (body) — all OFL, self-hosted
in `fonts/`. Static HTML + CSS, no JS, no build step.

## Files
- `index.html` — the page (beta version: TestFlight CTA)
- `cutline.css` — all styles + tokens
- `img/` — real app screenshots (simulator captures, status bars cropped)
  and Apple Watch captures
- `og.html` → `og-cutline.png` — share image source + render (command in
  the og.html header comment)
- Favicons — generated from the app icon via `sips -Z {512,180,32}`
