# ttt-web

Static web pages for **Tee Time Trainer**, served via GitHub Pages. Plain
HTML + CSS, no build step.

## Sites

- **`/`** (root) — the **Tee Time Trainer marketing landing page**
  (`index.html`). Productionized from the `design_handoff_landing_page`
  handoff: design tokens + the 3-T logo are inlined, Space Mono is self-hosted
  from `fonts/`, consumer copy + gold accent are locked, and the prototype-only
  Tweaks panel / editor JS were stripped. Only the scroll-reveal observer
  remains (with a no-JS / reduced-motion visible fallback).
- **`/cutline/`** — the **Cut Line** beta landing page (separate site, its own
  `cutline/` folder and stylesheets). Untouched by the root work.

## Assets

```
index.html              ← TTT landing page
fonts/                  ← Space Mono 400/400i/700/700i (self-hosted, root page)
og-ttt.png              ← 1200×630 share image for the landing
og-ttt.html             ← source template for the share image (regen below)
favicon-*.png           ← "T" plate favicon + apple-touch-icon (root)
favicon-ttt.html        ← source template for the favicon
.nojekyll               ← serve static assets as-is
cutline/                ← Cut Line site (see cutline/README.md)
```

## Regenerating the share image / favicon

Rendered from the real design system with headless Chrome:

```sh
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless --disable-gpu --force-device-scale-factor=2 \
  --window-size=1200,630 --screenshot=og-raw.png "file://$PWD/og-ttt.html"
sips -z 630 1200 og-raw.png --out og-ttt.png
```

Open Graph / Twitter tags carry **absolute** image URLs — if you re-host under a
different domain, update `og:image` / `og:url` / `canonical` in `index.html`.
